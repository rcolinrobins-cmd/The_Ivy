# The Ivy

A single-page website featuring a full-screen hero image with a "Welcome" title.

## Features

- Full-viewport hero section using a background image
- Responsive text sizing via CSS `clamp()`
- Elegant serif typography (Playfair Display, via Google Fonts)
- Dark overlay for text contrast against the image

## Tech Stack

- HTML5
- CSS3

## Getting Started

### Prerequisites

A modern web browser. No build tools, package managers, or dependencies are required.

### Installation

Clone the repository:

```bash
git clone https://github.com/rcolinrobins-cmd/The_Ivy.git
cd The_Ivy
```

### Usage

Open `index.html` directly in your browser:

```bash
open index.html
```

Or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
